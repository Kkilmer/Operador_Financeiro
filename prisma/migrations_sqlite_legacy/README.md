# Histórico legado de migrations SQLite

Estas migrations foram preservadas apenas para referência histórica da fase em que o projeto ainda evoluía sobre SQLite.

Elas **não** fazem mais parte da trilha ativa de migrations do projeto.

A trilha ativa usada para PostgreSQL está em:

- `prisma/migrations/`

Antes de executar qualquer `prisma migrate deploy` em ambiente novo, use apenas a baseline PostgreSQL atual.
